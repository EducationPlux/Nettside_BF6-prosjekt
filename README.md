# Battlefield Hub – skoleprosjekt

Norsk fanside om Battlefield 6 vg2. Bygget med HTML og CSS uten rammeverk.

## Åpne
Åpne mappen i VS Code, høyreklikk på BF6.html og velg «Open with Live Server». HTML-filen kan også åpnes direkte i nettleseren.

## Struktur
- BF6.html: forside.
- Hva-Er-BF6.html: spillet, historien og personene.
- BF6-Historikk.html: spillseriens tidslinje.
- Om-bf6.html: prosjektet og kildeoversikten.
- base.css: farger, font, meny og footer.
- forside.css / underside.css: sideoppsett og responsive regler.
- bilder/: lokale bilder, logo og favicon.
- dokumentasjon/design.html: wireframe, moodboard, farger og fontvalg.
- dokumentasjon/kilder.md: tekst- og bildekilder.
- dokumentasjon/framforing.md: stikkord til presentasjonen.
- dokumentasjon/kontroll.md: testresultater og avgrensninger.

Bildene tilhører EA / Battlefield. KI er brukt som hjelp til kode, design og tekst. Skissene dokumenterer strukturen under videreutviklingen.

## Innlevering
BF6-innlevering.zip inneholder bare BF6-prosjektet. Pakk ut og åpne BF6.html før levering i Teams.
CS2 og de fire ubrukte opprinnelige PNG-bildene beholdes i arbeidsmappen, men er ikke med i ZIP-pakken.
Les gjennom innholdet og øv på å forklare løsningen med egne ord før framføringen.
